# Portail d'entraide A2

Ouvrir index.html directement dans un navigateur. Aucun serveur, installation ou dépendance nécessaire.

Les données sont une simulation locale et disparaissent à l'actualisation.

## Conseil de vérification

Après deux clics, vérifier le nombre de créneaux et la durée totale ; après Recommencer, vérifier le retour à zéro.
